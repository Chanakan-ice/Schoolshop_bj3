ตั้งค่าระบบ Vercel API & Supabase Cloud

ระบบทำงานบน Vercel Serverless Function (/api/shop) โดยตรง และสามารถเชื่อมต่อกับ Supabase (Cloud Database ฟรี) เพื่อซิงก์ข้อมูลสินค้าและออเดอร์ข้ามเครื่องได้ทันที

* ดูได้ที่เมนู Project Settings > API ในแดชบอร์ด Supabase
* นำรหัส anon public มาใส่ที่นี่ เพื่อให้หน้าเว็บอ่านเขียนข้อมูลตรงกับ Supabase ได้ทันที
พร้อมใช้งานทันที (Zero-Config): หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะบันทึกข้อมูลในโหมด Local อัตโนมัติ ทำให้สั่งซื้อและจัดการสินค้าได้ทันทีโดยไม่มีข้อผิดพลาด

ตั้งค่าอีเมลแจ้งเตือนคุณครู/แอดมิน (Email Notification)

เมื่อมีคำสั่งซื้อใหม่ (COD) หรือมีผู้สั่งจองสินค้า (Pre-order) ระบบจะส่งอีเมลแจ้งเตือนรายละเอียดสินค้า ผู้สั่งซื้อ และสถานที่นัดรับ ไปยังอีเมลของคุณครูทันที (ไม่ต้องสมัคร Token ใช้งานได้ฟรีและเสถียร 100%)

* คั่นแต่ละอีเมลด้วยเครื่องหมายจุลภาค , หรือขึ้นบรรทัดใหม่ (หากเว้นว่างไว้ ระบบจะส่งเข้าอีเมล Google Account ที่เป็นเจ้าของสคริปต์อัตโนมัติ)
ข้อดีของระบบแจ้งเตือนทางอีเมล: ได้รับข้อมูลออเดอร์ครบถ้วน ทั้งตารางสินค้า ยอดเงิน ชื่อผู้สั่ง เบอร์โทร และจุดนัดรับ สามารถกดโทรหาผู้ซื้อได้โดยตรงจากอีเมล
